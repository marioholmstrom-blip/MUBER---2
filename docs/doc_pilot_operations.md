# Pilot operations

## Centro operativo
Notion funciona como tablero operativo.
Supabase funciona como backend operativo real.

## Métricas mínimas
- requests creados
- requests aceptados
- trips completados
- ingresos MUBER
- ingresos chofer
- viajes por estado

## Objetivo del piloto
Operar viajes reales y medir aprendizaje operativo.
