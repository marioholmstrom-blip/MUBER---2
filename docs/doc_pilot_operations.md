# Pilot operations

## Objetivo

Definir cómo MUBER 2 se conecta con la operación real del piloto.

## Centro operativo

### GitHub
Se usa para:
- estructura técnica
- documentación versionada
- specs
- changes
- reglas del sistema

### Notion
Se usa para:
- dashboard operativo
- métricas
- ingresos
- seguimiento diario
- plan del piloto
- base documental operativa

## Qué debe poder medir la operación

- solicitudes creadas
- solicitudes aceptadas
- viajes activos
- viajes completados
- ingresos MUBER
- ingresos chofer
- viajes por servicio
- viajes por estado
- viajes por medio de pago
- incidencias

## Operación mínima del piloto

La operación del piloto debe permitir:

1. recibir solicitud
2. aceptar solicitud
3. ejecutar viaje
4. finalizar viaje
5. registrar trazabilidad
6. revisar métricas

## Regla clave

La app y la operación deben conversar entre sí.  
No basta con que el flujo funcione: también debe poder medirse.
