# Verification guide

## Antes de cerrar una tarea
- verificar que no rompe el flujo actual
- verificar que escribe en Supabase correctamente
- verificar que el tracking refleja el estado real
- verificar que el cambio quedó documentado

## Pruebas mínimas
- User crea request
- Driver acepta
- se crea trip
- User ve tracking
- Driver puede avanzar estados
