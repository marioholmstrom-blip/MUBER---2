# Assisted flow

## Flujo
1. Elegir ayuda
2. Origen y destino
3. Inventario híbrido
4. Resumen + precio
5. Solicitar viaje
6. Tracking

## Tipos de ayuda
- adulto_mayor
- movilidad
- carga_delicada

## Resultado esperado
La solicitud asistida debe seguir el mismo backend base que User, con `service_type = mudanza_asistida`.
