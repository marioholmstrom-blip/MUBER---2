# User flow

## Flujo
1. Elegir servicio
2. Origen y destino
3. Inventario híbrido
4. Resumen + precio
5. Solicitar viaje
6. Tracking

## Datos principales
- service_type
- origin_text
- destination_text
- inventory_method
- estimated_price_clp
- status

## Resultado esperado
El usuario debe poder ver el estado real del viaje sin ambigüedad.
