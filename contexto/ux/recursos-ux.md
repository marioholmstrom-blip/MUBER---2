# MUBER · Recursos UX/UI

Lista de herramientas y recursos para investigación, prototipado y testing UX aplicables a MUBER. Mantiene la fuente original del archivo `enlaces ux 60.txt`.

> **Restricciones**: TEST por defecto, REAL solo con autorización explícita.

---

## Research & Discovery

- **[UsabilityHub](https://usabilityhub.com/)** - 5-second test, first click test, preference test para pantallas clave (HomeScreen, UserScreen paso 1, DriverScreen operativo).
- **[Optimal Workshop](https://www.optimalworkshop.com/)** - Card sorting y tree testing para validar la IA de navegación y taxonomía de inventario.
- **[Hotjar](https://www.hotjar.com/)** - Heatmaps y grabaciones en web TEST para entender scroll depth en DriverScreen desktop y UserScreen móvil.

## Encuestas & Métricas

- **[QuestionPro - Escala de Likert](https://www.questionpro.com/blog/es/que-es-la-escala-de-likert-y-como-utilizarla/)** - Encuestas post-flujo con escala 1-5 (claridad, confianza, esfuerzo percibido).
- **[Interaction Design Foundation - UCD](https://www.interaction-design.org/literature/topics/user-centered-design)** - Marco teórico de User-Centered Design.

## Customer Journey & Maps

- **[WebFX - Customer Journey Maps](https://www.webfx.com/blog/web-design/customer-journey-maps/)** - Guía para crear journey maps por rol.
- **[UXPressia](https://uxpressia.com/)** - Herramienta para journey maps de User, Assisted y Driver.
- **[Tesis UDL](https://repositori.udl.cat/server/api/core/bitstreams/10e3d2a9-0b01-438b-af22-80ed33361b48/content)** - Referencia académica sobre UX.

## Wireframes & Diagramas

- **[diagrams.net](https://app.diagrams.net/)** - Wireframes y sitemaps web + flujos nativos.
- **[GlooMaps](https://www.gloomaps.com/)** - Sitemaps rápidos.
- **[Whimsical](https://whimsical.com/)** - Wireframes y flows.
- **[Miro](https://miro.com/)** - Canvas colaborativo para workshops.
- **[XMind](https://www.xmind.net/)** - Mind maps para taxonomía de inventario y estados de viaje.
- **[MindMeister](https://www.mindmeister.com/es)** - Mind maps colaborativos.
- **[Coggle](https://coggle.it/?lang=es)** - Mind maps simples.

## Prototipado Alta Fidelidad

- **[Axure](https://www.axure.com/)** - Prototipado interactivo complejo.
- **[Figma - Guía UB](https://diposit.ub.edu/dspace/bitstream/2445/189524/1/guia_uso_figma.pdf)** - Guía de uso de Figma.
- **[Shortcuts.design - Figma](https://shortcuts.design/tools/toolspage-figma/)** - Atajos de Figma.

## Diagramas de Proceso

- **[LucidChart ES](https://www.lucidchart.com/pages/es)** - Diagramas de flujo (máquina de estados de trip_status y payment_status).

## Traducción

- **[DeepL ES](https://www.deepl.com/es/translator)** - Traducción de copy clave si se interna­cionaliza.
